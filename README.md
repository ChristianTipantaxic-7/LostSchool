# LostSchool

## Problema
En la institución educativa, los estudiantes suelen perder objetos personales como cuadernos, mochilas, cartucheras, botellas y prendas de vestir. Muchas veces estos objetos no pueden ser recuperados porque no existe un medio organizado para registrar los objetos encontrados y comunicar quién los está buscando.

## Solución
La aplicación permitirá registrar objetos encontrados y consultar los objetos publicados por otros estudiantes. De esta manera, facilitará la búsqueda y recuperación de pertenencias dentro de la institución educativa.

## Objetivos
- 1. Permitir registrar objetos encontrados mediante un formulario con nombre, categoría, descripción y lugar.
- 2. Mostrar al menos 5 objetos registrados en la pantalla principal con sus datos principales.
- 3. Permitir consultar la información completa de cada objeto al seleccionarlo.
- 4. Conservar los objetos registrados después de cerrar y volver a abrir la aplicación.
- 5. Verificar que el registro, la visualización y la consulta funcionen correctamente con 5 objetos diferentes.

## Habilidades
- - Desarrollar aplicaciones móviles utilizando React Native y TypeScript.
- - Crear y organizar componentes e interfaces en Expo.
- - Manejar estados y eventos mediante useState.
- - Guardar y consultar información utilizando AsyncStorage.
- - Realizar pruebas de funcionamiento en un dispositivo Android.
- - Aplicar conocimientos básicos de programación

## Alcance inicial
- Pantalla principal con una lista de objetos encontrados.
- Formulario para registrar objetos con nombre, categoría, descripción y lugar.
Visualización de los datos principales de cada objeto en la lista.
Pantalla de detalles para consultar la información completa de un objeto.
Almacenamiento local mediante AsyncStorage.
Actualización de la lista después de registrar un nuevo objeto.

## Restricciones
- No incluirá fotografías de los objetos en la primera versión.
- No tendrá inicio de sesión ni registro de usuarios.
- No incluirá chat ni mensajería.
- No tendrá notificaciones automáticas.
- No permitirá cambiar el estado de los objetos.
- No incluirá filtros ni búsquedas avanzadas.
- La información se almacenará localmente en el dispositivo.
- Las funciones adicionales se reservarán para futuras versiones.
